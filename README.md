# Profile Card

A simple and responsive personal profile card built using **HTML and CSS**. This project presents personal information in a clean, modern layout.

## Features

- Clean and attractive user interface
- Profile image and personal details
- Social media links
- Responsive design
- Built using basic HTML and CSS

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
profile-card/
├── index.html
├── style.css
├── profile.png
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Purpose

This project was created to practice HTML structure, CSS styling, and webpage layout while building a personal profile card.
